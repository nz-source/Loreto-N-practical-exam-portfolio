3. What is an API?
    - Application Programming Interface
    - It is a set of rules that allows different software application to 
    communicate with each other.
    - Example: The client of a shop send and order, the API recieved the request, then the server process the request'
    the API return the response to the client.
    -In short API is an middleware used to communicate both parties.
